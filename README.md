# Predicción de Daño en Veredas por Arbolado Urbano
Este proyecto analiza datos del censo de árboles de la ciudad de Nueva York para anticipar si un árbol puede llegar a romper o levantar la vereda donde está plantado. A partir de características cotidianas —como el grosor del tronco, la especie del árbol, el espacio donde crece y si sus raíces tienen obstáculos en el suelo—, el objetivo es identificar cuáles son los factores que más dañan las aceras y predecir cuándo es probable que ocurra este problema, facilitando así una mejor planificación del mantenimiento urbano y la convivencia entre la vegetación y los peatones.
