01 · El problema

Una vereda dañada afecta la movilidad cotidiana

Pregunta

¿Qué características de árboles y entorno se asocian con que la vereda haya sido registrada como dañada?

Uso potencial

Explorar patrones que ayuden a formular hipótesis para inspecciones, siempre con revisión humana y evidencia local.

Qué no hacemos

No inferimos causalidad, fecha de rotura ni prioridad real de obras.

03 · EDA y preparación

De registros a variables analizables

Calidad

Revisamos faltantes, clases de sidewalk, diámetros y registros no elegibles.

Variables derivadas

Resumimos conflictos de raíces, tronco y ramas; agrupamos especies poco frecuentes.

Prevención de leakage

Excluimos `sidewalk` de X; codificación e imputación se integran al pipeline de ML.

En el conjunto original, cerca de 29% de las veredas etiquetadas figura como Damage y 71% como NoDamage. Verificar cifras en la muestra usada para reentrenar.

04 · Aprendizaje supervisado

El modelo recupera parte de la clase minoritaria

Evaluación

GridSearchCV, validación estratificada y test separado de 20.000 registros.

Mejores parámetros: 100 árboles, profundidad 16, mínimo 10 observaciones por hoja.

Test · clase Damage

F1 = 0,548

Recall 0,615 · Precisión 0,494 · ROC-AUC 0,741

Accuracy 0,708. Dummy mayoritario: accuracy 0,712, F1 Damage = 0.

La precisión moderada implica falsas alarmas; recall 0,615 implica que también quedan daños observados sin detectar. La matriz de confusión es [[10.623, 3.622], [2.216, 3.539]].

05 · Aprendizaje no supervisado

Grupos exploratorios, no categorías de riesgo

K-Means · 10.000 árboles

Silhouette máximo con k=3: 0,282. Grupos de 670, 7.004 y 2.326 árboles; el último tuvo mayor diámetro mediano (16 pulgadas) y más conflictos radiculares (mediana 1).

DBSCAN

5 grupos, 1,2% de puntos considerados ruido; silhouette 0,333 entre puntos no-ruido.

La separación es modesta y depende de variables, codificación y parámetros. No son grupos de riesgo validados.

06 · API y demo

Del notebook a una interfaz reproducible

Entrenamiento

python Final/train.py

Genera el pipeline y métricas en `Final/artifacts/`.

Servicio

uvicorn Final.app:app --reload

FastAPI: `/health`, `/predict` y documentación `/docs`.

La API devuelve clase estimada y probabilidad para el estado observado. La probabilidad no está calibrada para uso operativo; no automatizar decisiones.

07 · Responsabilidad y cierre

Una señal estadística no reemplaza una política pública

  • El censo es de NYC y de 2015; voluntariado, faltantes y cobertura desigual pueden sesgar los resultados.
  • Variables y etiqueta se relevaron en el mismo período: no hay evidencia temporal para pronosticar roturas futuras.
  • Las variables geográficas pueden actuar como proxies y reforzar desigualdades de mantenimiento.
  • Una aplicación real exige datos recientes, evaluación por zona, inspección humana, auditoría y consulta comunitaria.

Aprendizaje principal: definir bien la pregunta y los límites importa tanto como elegir el algoritmo.
